# Ritm Launcher

Твій Minecraft. Твій ритм.

Ritm Launcher — лаунчер Minecraft: Java Edition для Android.
Файли гри завантажуються з офіційних серверів Mojang. Проєкт не афілійований з Mojang чи Microsoft.

## Збірка

./gradlew :app_mojo:assembleDebug
